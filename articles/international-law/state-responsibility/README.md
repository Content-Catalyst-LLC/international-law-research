# State Responsibility in International Law

Companion research folder for the State Responsibility article in the International Law Foundations series.

## Purpose

This folder stores supporting material for the article, including:

- ARSIWA source metadata
- ILC commentary source notes
- attribution, breach, aid-or-assistance, and countermeasures concept mapping
- serious breaches and jus cogens notes
- Palestine, Gaza, and third-state responsibility notes
- ICJ and PCIJ case references
- quote logs
- SQL schema for state-responsibility research metadata
- lightweight Python utilities for exporting sources and validating metadata
- editorial notes for future article revisions
