# Doctrine Summary

The United Nations Charter framework treats force as presumptively unlawful except where the Security Council authorizes enforcement action or where a state acts in individual or collective self-defense after an armed attack.

Core analytical questions:

1. Has there been an armed attack?
2. Is the responding state the victim state or acting at the victim state's request?
3. Is the use of force necessary?
4. Is it proportionate?
5. Was the Security Council notified?
6. Is the claim actually defensive, or is it retaliation, prevention, reprisal, punishment, or annexation by another name?
7. How does the claim interact with collective security, occupation, non-intervention, and state responsibility?
