# The Westphalian System and State Sovereignty

Companion research folder for the Westphalian System and State Sovereignty article in the International Law Foundations series.

## Purpose

This folder stores supporting material for the article, including:

- Peace of Westphalia source metadata
- UN Charter sovereign equality source notes
- Friendly Relations Declaration source notes
- Montevideo Convention statehood source notes
- sovereignty, territorial authority, recognition, and non-intervention concept mapping
- Westphalian myth and critique notes
- empire and decolonization notes
- quote logs
- SQL schema for sovereignty and state-system research metadata
- lightweight Python utilities for exporting sources and validating metadata
- editorial notes for future article revisions
