# Reservations, Interpretation, and Validity in Treaty Law

Companion research folder for the Reservations, Interpretation, and Validity article in the International Law Foundations series.

## Purpose

This folder stores supporting material for the article, including:

- Vienna Convention source metadata
- reservations doctrine source notes
- treaty interpretation source notes
- validity and invalidity source notes
- ICJ Genocide Reservations advisory opinion references
- ILC Guide to Practice on Reservations to Treaties metadata
- ILC subsequent agreements and subsequent practice materials
- legal concept mapping
- quote logs
- SQL schema for treaty-doctrine research metadata
- lightweight Python utilities for exporting sources and validating metadata
- editorial notes for future article revisions
