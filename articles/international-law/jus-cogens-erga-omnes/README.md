# Jus Cogens and Erga Omnes

Companion research folder for the Jus Cogens, Erga Omnes, and Peremptory Norms article in the International Law Foundations series.

## Purpose

This folder stores supporting material for the article, including:

- Vienna Convention Articles 53 and 64 source metadata
- ILC jus cogens draft conclusions and commentary metadata
- erga omnes and erga omnes partes case references
- legal-consequence concept mapping
- non-recognition and non-assistance notes
- quote logs
- SQL schema for peremptory-norm research metadata
- lightweight Python utilities for exporting sources and validating metadata
- editorial notes for future article revisions
