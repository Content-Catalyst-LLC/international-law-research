# Fragmentation and Coherence in International Legal Order

Companion research folder for the Fragmentation and Coherence article in the International Law Foundations series.

## Purpose

This folder stores supporting material for the article, including:

- ILC fragmentation source metadata
- systemic integration notes
- lex specialis and lex posterior concept mapping
- self-contained regime notes
- ICJ Oil Platforms and Jurisdictional Immunities references
- regime-complex and institutional pluralism notes
- quote logs
- SQL schema for fragmentation/coherence research metadata
- lightweight Python utilities for exporting sources and validating metadata
- editorial notes for future article revisions
