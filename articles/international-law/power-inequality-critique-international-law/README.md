# Power, Inequality, and the Critique of International Law

This folder supports the Sustainable Catalyst article **Power, Inequality, and the Critique of International Law**.

The folder is intentionally a research/support package rather than a copy of the WordPress article. It contains metadata, authority notes, further-reading notes, structured matrices, a small SQL schema, and generated JSON outputs that document the article's research architecture.

## GitHub content policy

The full WordPress-ready article HTML is not stored in this repository. WordPress is the publication layer. GitHub is the research/support layer.

## Folder contents

- `metadata/article_metadata.json` — article title, slug, SEO metadata, excerpt, tags, and navigation metadata.
- `sources/primary_authorities.md` — primary legal materials and institutional authorities.
- `sources/further_reading.md` — critical scholarship and interpretive sources.
- `data/*.csv` — structured matrices on critique, power, inequality, and legal domains.
- `sql/power_inequality_critique_schema.sql` — lightweight schema for research inventory use.
- `python/build_power_inequality_outputs.py` — helper that builds JSON summary outputs.
- `outputs/*.json` — generated support summaries.
