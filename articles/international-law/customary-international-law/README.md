# Customary International Law

Companion research folder for the Customary International Law article in the International Law Foundations series.

## Purpose

This folder stores supporting material for the Customary International Law article, including:

- Article 38 and ILC customary-law source metadata
- state practice and opinio juris concept mapping
- ICJ case references for custom identification
- legal-source quote logs
- SQL schema for customary-law research metadata
- lightweight Python utilities for exporting sources and validating metadata
- editorial notes for future article revisions
